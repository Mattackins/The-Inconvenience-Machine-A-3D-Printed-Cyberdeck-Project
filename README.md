# The-Inconvenience-Machine-A-3D-Printed-Cyberdeck-Project
A 3D printed Cyberdeck Project that serves as more of a 3D modelling and software benchmark showcase rather than an electrical project. This project started late January 2026 and completed November 2026. (Total time spent on this project is approximately a minimum of 30 hours. This project is comprised of two separate phases of the cyberdeck.)
